# Selected Data and ML Work

Privacy-safe case studies based on freelance project experience in sports forecasting, catalog data collection, and ML problem framing.

This repository contains independently authored examples and synthetic data only. It excludes client names, account details, contract messages, datasets, scraped catalogs, images, and original client deliverables. These examples demonstrate relevant methods; they are not the original contracted systems.

## Projects

- [NHL game outcome modeling](projects/nhl-game-prediction/README.md): a small, reproducible Poisson-scoring illustration using synthetic expected-goal inputs.
- [Catalog data pipeline](projects/catalog-data-pipeline/README.md): normalize and deduplicate a synthetic movie/series catalog while retaining source provenance.
- [ML problem framing](projects/ml-project-framing/README.md): a reusable checklist for defining a target, leakage-safe evaluation, and appropriate metrics before modeling.

## Scope and attribution

The examples are original portfolio material. Public source code and sample rows were created for this repository. No confidential or client-owned source code or data is included. Project descriptions are generalized and do not imply client endorsement, production use, or measured model performance.
